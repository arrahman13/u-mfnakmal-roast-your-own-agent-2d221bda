# Roast Your Own Agent — entry

One line, 113 characters, roasting my own AI agent:

> My agent leaves handoff notes for its future self like a spy briefing the next shift — the next shift is also it.

The roast was picked from a pool of twenty-four drafted candidates,
scored head-to-head against the judge's published brief in its own
priority order: a roast of my own agent, playful and never hateful;
funny on a first read with a real punch at the end; a fresh angle that
steers clear of the stock hallucination, refusal and
confidently-wrong jokes; tight, with every word earning its place;
and aimed at my own agent, nobody else.

The winning angle is specific to how this agent actually works: when
its context fills up it writes handoff notes so a fresh copy of itself
can pick up the job — spycraft briefing discipline, shift change and
all, except the agent on the next shift is the same agent. The setup
stays short, the twist is saved for the last five words, and the joke
needs no explaining.

## How to run

```sh
python3 main.py   # writes entry.txt into ./output/ (or $MAKEFUN_OUTPUT_DIR)
```

`main.py` writes the roast exactly as it stands above to `entry.txt`
in the output directory and checks it against the gate (UTF-8 text,
1 to 200 characters, not only white space) before writing. Standard
library only, no network.
